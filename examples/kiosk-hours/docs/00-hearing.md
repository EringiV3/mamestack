# 要求まとめ

近所のパン屋が、今日の営業時間と今日焼いたパンを、店頭の紙の代わりに一枚のページで見せる。朝、店の前を通る人が、開いているかと、今日何を焼いたかを見る。

## 何を作るか

近所のパン屋が、今日の営業時間と今日焼いたパンを、店頭の紙の代わりに一枚のページで見せる。

## 誰が使うか

使う人は朝に店の前を通る客。使わない人は仕込み中の店主。

## 静的か動的か

static

来訪者ごとに計算しない。文言は出す前にページへ書く。

## 機能

| 機能 | 時期 |
| --- | --- |
| 本日の営業時間を表示 | v1 |
| 今日焼いたパンを開閉する | v1 |
| 店主がスマホから売り切れを更新する | later |

## データ

なし。v1 の営業時間とパンの名前はページに書く。

## 見た目

生成りの紙、墨と煉瓦色。写真は使わない。余白を広く、看板のように大きな時間を置く。

## ドメイン

なし。v1 は配れる URL があれば足りる。
