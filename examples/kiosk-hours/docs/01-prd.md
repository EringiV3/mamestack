# PRD

麦畑ベーカリー。近所のパン屋が、今日の営業時間と今日焼いたパンを、店頭の紙の代わりに一枚のページで見せる。

## 概要

朝に店の前を通る人が、紙の看板を探さずに、今日開いている時間と、今日焼いたパンの名前を見る。v1 のあと、店先での「やってますか」がページを開けば足りる。

## 使う人

使う人は朝に店の前を通る客。使わない人は仕込み中の店主。店主は v1 ではページを編集して出す人であり、画面の利用者ではない。

## v1

| 機能 | 完了の見え方 |
| --- | --- |
| 本日の営業時間を表示 | 店名、8:00–15:00、水曜は焼かない、が見える。パンの一覧は閉じている。 |
| 今日焼いたパンを開閉する | 「今日焼いたパン」でカンパーニュ、レーズン、塩バターロールが開き、もう一度で閉じる。 |

## 後回し

店主がスマホから売り切れを更新する。保存と認証が要り、v1 の「紙の置き換え」を超える。このサンプルの PR には入れない。

## データ

なし。v1 の営業時間とパンの名前はページに書く。売り切れのフラグは持たない。

## 見た目

生成りの紙、墨と煉瓦色。写真は使わない。余白を広く、看板のように大きな時間を置く。

## ドメイン

なし。v1 は配れる URL があれば足りる。独自ドメインの購入はしない。

## 成功

ページを開くと営業時間が読め、ボタンで本日のパンが開き、もう一度で閉じる。

## 対象外

管理画面、売り切れ、在庫、注文、写真、独自ドメイン、来訪者ごとの文章。
