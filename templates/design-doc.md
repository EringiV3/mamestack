# 設計書

## 選定

規則の適用結果を一文で書く。この文を `approve-design --reason` にそのまま渡す。

- 保存の無い静的サイト: Astro
- アプリケーション、または保存がある: Void

採用する名前（Astro または Void）を本文に残す。

## 構成

何が静的 HTML で、どこだけサーバーか。クライアント JS を足すなら、その操作の名前。UI フレームワークを足さないなら、そう書く。

## 性能

- アプリ: コマンドは `void deploy`。資源の作成とマイグレーションがあるので確認する。
- Wrangler は書かない。
